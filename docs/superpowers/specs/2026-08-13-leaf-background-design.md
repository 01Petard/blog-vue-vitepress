# 全站叶片背景设计

## 目标

为当前 VitePress 站点增加与参考站点一致的叶片平铺背景，并支持浅色、深色模式。背景覆盖首页、文章页、分类页和侧栏页面，不改变现有内容与页面布局。

## 参考实现

以参考站点线上构建产物为基准，不采用其源码仓库中的旧版 `background-size: cover` 写法。线上最终参数如下：

- 背景资源尺寸：`650 × 613` PNG
- 背景定位：固定于视口
- 背景重复：`background-repeat: repeat`
- 页面遮罩：径向渐变
- 浅色遮罩基色：`255, 255, 255`
- 深色遮罩基色：`20, 20, 20`
- 渐变透明终点：`700%`
- 浅色内容层：`rgba(255, 255, 255, .1)`
- 深色内容层：`rgba(20, 20, 20, .7)`

## 分层结构

页面视觉层级从下到上为：

1. VitePress 浅色或深色基础底色
2. 固定于视口的叶片 PNG 平铺层
3. 随主题切换的径向渐变遮罩层
4. 导航栏、侧栏、正文区和首页功能块的半透明内容层
5. 页面文字、图片和交互控件

叶片层仅承担装饰，不接收鼠标事件，也不参与文档流。内容层负责可读性，避免依靠加重整个页面遮罩来压低叶纹。

## 全站适配

- 在全局主题 CSS 中实现背景，不修改各 Markdown 页面
- 首页保持叶纹可见，现有 Hero 与功能块布局不变
- 普通文章页为正文阅读区域增加半透明背景
- 带侧栏页面为导航栏、左侧栏、正文区和右侧目录提供独立半透明背景
- 弹窗、搜索框、代码块等已有 VitePress 组件继续使用自身背景色
- 移动端保持原始图片尺寸和平铺密度，不单独拉伸背景
- 打印模式移除装饰背景，保持打印内容清晰

## 资源与代码边界

新增本地资源：

- `docs/.vitepress/theme/assets/leaf-background.png`

修改全局样式：

- `docs/.vitepress/theme/index.css`

背景资源保存到项目内，构建和部署不依赖参考站点。CSS 使用自定义变量集中管理浅色、深色遮罩与内容层透明度，避免分散硬编码。

## 兼容性与性能

- 不引入 JavaScript、Vue 组件或第三方依赖
- 使用单张小尺寸 PNG 平铺，浏览器只下载一次并复用纹理
- 使用伪元素绘制固定背景，避免长页面生成超大背景位图
- 保留 VitePress 原生 `.dark` 类切换机制，无主题闪烁逻辑变更
- 背景伪元素使用负层级并禁用指针事件，不影响链接、搜索和滚动

## 验收标准

- 首页、普通文章页、带侧栏文章页均显示连续叶片背景
- 浅色模式下叶片为淡蓝色，正文对比度清晰
- 深色模式下底色接近 `#141414`，叶片为低亮度蓝灰色
- 主题切换后遮罩和内容层同步变化，无需刷新
- 背景随页面滚动固定，图案无拉伸、接缝或空白区域
- 桌面端与移动端均不遮挡导航、侧栏、正文和交互控件
- `pnpm build` 成功完成

## 非目标

- 不复刻参考站点的博客卡片布局、头像、文章列表或侧栏组件
- 不修改当前首页文案、文章内容、站点导航和主题色
- 不重新设计叶片图案，也不使用远程图片地址
