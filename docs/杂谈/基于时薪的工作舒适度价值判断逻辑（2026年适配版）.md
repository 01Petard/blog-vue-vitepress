# 选工作的核心标尺——论薪资性价比

## 一、评价指标

核算规则和计算公式：

- 个人公积金 = 公积金基数 × 公积金比例，公司公积金与个人等额；
- 社保个人缴纳：基数 × 10.5%（其中养老8%、医疗2%、失业0.5%）；
- 公积金单边缴纳：基数 × 12%（个别有特殊比例）；
- 月到手 = 月薪 - 个人社保 - 单边公积金，不考虑个人所得税；
- 月总收益 = 月到手 + 双边公积金 = 月薪 - 个人社保 + 公司公积金；
- 年包 = 月总收益 × 12，仅考虑12薪固定薪资，不考虑年终奖、项目奖金等其他收入；
- 时薪根据年收益、公司工作每月出勤天数和工作时长进行综合计算，可作为工作性价比参考值。

叠甲申明：

1. 本表**不含年终奖、股票补贴、餐补房补、签字费等额外收入**，实际总包会高于表格中年综合收益；
2. 公积金基数≠月薪是常见降本方式（低基数缴纳），会直接拉低长期隐性收入；
3. 时薪是综合了出勤天数、加班强度的**性价比核心指标**，评估 offer 不能只看税前月薪；
4. 工作氛围分为四类：结果导向｜快节奏｜秩序规范｜层级森严，作为主观感受参考项。

## 二、案例参考

根据个人体感和阅历，本人对不同**时薪**的工作进行舒适度排名：

- 大于70：价比高，即便工作强度高回报也匹配，强度低属于优选，适合长期发展
- 60～70：收益尚可，整体可以接受，若无明显短板不需要主动跳槽
- 50～60：长期发展受限，物质提升空间小，无法追求诗和远方
- 低于50：纯牛马，投入产出失衡，偏消耗，优先寻找更好机会，不建议长期停留
